# Introducció
Una vegada instal·lat el SGBD, ho següent es començar amb les tasques d'administració. La 1a tasca seria configurar el servidor de la manera més eficient possible, d'acord amb les nostres necessitats. Per això hauríem de conèixer les variables i opcions de MySQL més importants. Una altra tasca important és entendre i localitzar els fitxers log i d'error que genera el servidor. Quan ho tenim instal·lat com a servei, no mostra missatges mentre interactuem amb ell i, si ocorreix algun problema, haurem de conèixer el contingut d'aquests fitxers per poder identificar-lo. Per poder saber l'estat del servidor en cada moment, també haurem de conèixer les variables del sistema i d'estat del servidor i, lògicament, les intruccions per a realitzar la pertinent gestió d'aquestes variables.
